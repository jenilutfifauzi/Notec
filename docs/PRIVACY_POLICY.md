# Kebijakan Privasi (Privacy Policy) - Notec

**Terakhir Diperbarui:** 6 Oktober 2026

Aplikasi **Notec** ("kami", "aplikasi", atau "Notec") menghargai dan melindungi privasi setiap pengguna. Kebijakan Privasi ini menjelaskan bagaimana data dan informasi diperlakukan saat Anda menggunakan aplikasi Notec pada perangkat seluler Anda.

---

## 1. Penyimpanan Data Lokal & Offline
- Seluruh data transaksi, kategori, dompet/rekening, dan catatan anggaran keuangan yang Anda masukkan ke dalam aplikasi Notec **disimpan secara lokal 100% pada perangkat Anda** menggunakan database lokal (SQLite).
- Kami **TIDAK** mentransfer, mengunggah, atau menyimpan data keuangan pribadi Anda ke server eksternal, cloud pribadi pihak ketiga, atau sistem penyimpanan jarak jauh mana pun.
- Anda memiliki kontrol penuh atas data Anda; menghapus aplikasi atau membersihkan cache/data aplikasi akan menghapus seluruh data yang tersimpan di perangkat.

## 2. Izin Akses Perangkat (Permissions)
Aplikasi Notec hanya meminta izin minimum yang diperlukan untuk menjalankan fitur produktivitas yang Anda aktifkan:
- **Mikrofon (`RECORD_AUDIO`) & Pengenalan Suara (`Speech Recognition`):** Digunakan semata-mata saat Anda menekan tombol mikrofon untuk input transaksi berbasis suara. Suara Anda diproses secara langsung oleh layanan speech recognition perangkat Android Anda dan **TIDAK PERNAH** direkam, disimpan, atau dikirimkan ke server kami.
- **Penyimpanan Lokal:** Digunakan semata-mata untuk membaca dan menulis database SQLite lokal serta mengekspor/mengimpor backup transaksi secara mandiri oleh pengguna.

## 3. Tidak Ada Pengumpulan atau Pembagian Data Pribadi (No Data Collection)
- Kami **TIDAK** mengumpulkan data identifikasi pribadi seperti nama lengkap, nomor telepon, alamat email, nomor kartu kredit/debit, atau nomor rekening bank.
- Kami **TIDAK** melacak lokasi geografis (GPS).
- Kami **TIDAK** menjual, menyewakan, membagikan, atau memonetisasi data pengguna kepada pihak ketiga, pengiklan, atau pialang data mana pun.

## 4. Tidak Ada Iklan Pihak Ketiga (No Ads)
Aplikasi Notec bebas dari iklan pihak ketiga (tidak mengandung Google AdMob, Unity Ads, atau SDK periklanan lainnya). Dengan demikian, tidak ada data analitik perilaku pengguna yang dilacak untuk keperluan penargetan iklan.

## 5. Fitur Keuangan (Financial Features Disclaimer)
- Notec adalah alat pencatatan dan pengelolaan keuangan pribadi mandiri (*Personal Financial Management / Budgeting & Expense Tracker*).
- Notec **BUKAN** lembaga keuangan berizin, **BUKAN** penyedia pinjaman online (peer-to-peer lending), **BUKAN** fasilitas perbankan digital, dan **BUKAN** platform investasi.
- Notec tidak pernah meminta kredensial perbankan, PIN, atau kata sandi rekening keuangan Anda.

## 6. Perubahan Kebijakan Privasi
Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu jika terdapat pembaruan fitur pada aplikasi. Setiap perubahan akan diperbarui pada halaman ini dengan tanggal revisi terbaru.
